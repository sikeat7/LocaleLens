Scan details

One URL. A few new perspectives.

  1. Choose a website.

    Paste a complete URL. Use advanced settings to add specific page paths; LocaleLens does not crawl the whole site.

  2. Put its layout to the test.

    We compare original pages with longer text and right-to-left layouts in a separate Chromium browser.

  3. Review what changed.

    Open a report for screenshots, element selectors, and suggested fixes. Findings can need human review.

Your history is stored in a local SQLite database. Reports stay on this computer until you share them. Visited websites make their usual network requests.

If a scan says Chromium is missing, close this panel and reopen it using the project launcher, which installs the browser on first use.

Delete this scan?

This removes its history and saved reports from this computer. This cannot be undone.
